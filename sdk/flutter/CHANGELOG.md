# Changelog

## 0.3.1

- Republishes the LALIGENCE eKYC backend SDK after `0.3.0` was already reserved on pub.dev.
- Keeps the same typed backend client, upload helpers, response models, and expanded README documentation.

## 0.3.0

- Replaces the package implementation with the LALIGENCE eKYC backend SDK.
- Adds typed client methods for verification sessions, passport upload, challenge completion, selfie analysis, face enrollment, returning face login, and testing profile helpers.
- Adds typed response models for verification decisions, OCR results, biometric analysis, fraud signals, profile enrollment, and face login.
- Supports image uploads from file paths or bytes.
